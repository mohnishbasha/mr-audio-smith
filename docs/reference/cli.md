## Exit codes

Every failure is a typed error with a code, a stage, and an actionable hint.
Stack traces appear only with `--debug`.

| Exit code | Error class | Code | Stage |
|---|---|---|---|
| 1 | `AudioSmithError` | `internal_error` | `any` |
| 2 | `UsageError` | `usage` | `config` |
| 3 | `PreflightError` | `preflight_failed` | `preflight` |
| 4 | `ExtractError` | `extract_failed` | `extract` |
| 4 | `FetchError` | `fetch_failed` | `fetch` |
| 5 | `ScriptInvalidError` | `script_invalid` | `script` |
| 5 | `LLMError` | `llm_failed` | `script` |
| 6 | `SynthesisError` | `synthesis_failed` | `synth` |
| 7 | `MasteringError` | `mastering_failed` | `master` |
| 8 | `ConsentError` | `consent_missing` | `voice` |

Exit code 0 means success. `site` exits 6 when any page failed.
